# 📝 Todo App (CLI)

Bu proje, Python ile yazılmış basit bir **yapılacaklar listesi** uygulamasıdır.  
Amaç, GitHub üzerinde örnek bir proje sergileyerek repo kalitesini arttırmaktır. 🚀

## Özellikler
- Görev ekleme
- Görevleri listeleme
- Görev silme
- Verileri JSON dosyasında saklama

## Kurulum
```bash
git clone https://github.com/KULLANICI_ADIN/todo-app.git
cd todo-app
pip install -r requirements.txt
